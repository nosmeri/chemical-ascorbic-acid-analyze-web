Savitzky-Golay 필터는 각 데이터 지점을 중심으로 좌우 대칭인 윈도우 [-m, +m] 범위의 점들을 국소 다항식 피팅합니다.

윈도우 크기는 2m + 1개가 되므로, 정가운데 중심점(m=0)을 정확히 기준 삼으려면 반드시 홀수여야 합니다.

⚠️ 짝수 크기를 사용할 경우 중심점이 데이터와 데이터 사이의 가상 위치에 놓이게 되어, 시간 축 위상 왜곡(Phase shift/시간 지연)이 발생하여 정확한 적정 종말점 위치가 변형됩니다.
